# Telegram Username Scanner

## 1. Установка

Установите Python 3.10+.

Откройте CMD в папке программы и выполните:

```bat
py -m pip install -r requirements.txt
```

## 2. Telegram API

Получите API ID и API Hash в официальном кабинете Telegram:
https://my.telegram.org

Создайте приложение в разделе API Development Tools.

## 3. Запуск

```bat
py telegram_username_scanner.py
```

При первом запуске программа попросит:
- номер телефона;
- код, пришедший в Telegram;
- пароль 2FA, если он включён.

После авторизации рядом появится файл `telegram_scanner.session`.
Никому его не передавайте: он содержит авторизационную сессию Telegram.

## 4. Что умеет программа

- генерировать случайные username;
- проверять их через Telegram API;
- показывать свободные username в окне;
- автоматически сохранять свободные username в `available.txt`;
- сохранять результаты в выбранный TXT-файл;
- задавать длину от 5 до 32 символов;
- выбирать буквы / буквы+цифры / цифры;
- использовать префикс и суффикс;
- работать с несколькими аккаунтами одновременно (вкладка «Аккаунты»);
- задавать отдельный прокси (socks5/socks4/http) для каждого аккаунта;
- останавливать сканирование;
- обрабатывать FloodWait Telegram.

## Важно

Не ставьте слишком маленькую задержку (рекомендуется 1 сек. и больше). Telegram жёстко ограничивает
частоту проверок username; при FloodWait программа сама ждёт и увеличивает задержку.

Файлы `.session` и `available.txt` создаются в папке программы.

## Несколько аккаунтов и прокси

- Вкладка «Аккаунты» → «Добавить»: название и (по желанию) прокси. Номер и код программа спросит при первом запуске.
- Каждый аккаунт хранится в папке `sessions/`, список и API ID/Hash — в `accounts.json` (в открытом виде, не передавайте).
- Все включённые аккаунты проверяют ники параллельно, у каждого своя задержка и свой прокси.
- Старый аккаунт (`telegram_scanner.session`) подхватывается автоматически.
- Формат прокси: `socks5://user:pass@host:port`, `http://host:port`, `host:port` или `host:port:user:pass`.
- Если у аккаунта FloodWait дольше 5 минут, он отключается до конца запуска, остальные продолжают.
