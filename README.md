# 🎯 Telegram Username Scanner

Программа для поиска свободных (незанятых) username в Telegram с поддержкой мультиаккаунта и прокси.

**NEW**: Поддержка SOCKS5 / SOCKS4 / HTTP прокси для каждого аккаунта отдельно.

### ⚠️ ВАЖНО

Файлы `.session` и `accounts.json` содержат доступ к вашим аккаунтам Telegram.

## ⚙️ Использование

1. Установите **Python 3.10+**
2. Откройте CMD в папке программы и выполните:
   ```bat
   py -m pip install -r requirements.txt
   ```
3. Получите **API ID** и **API Hash** на https://my.telegram.org (раздел API Development Tools)
4. Запустите программу:
   ```bat
   py telegram_username_scanner.py
   ```
5. При первом запуске введите:
   - номер телефона;
   - код из Telegram;
   - пароль 2FA (если включён)

## ℹ️ Краткие описания файлов

- **`telegram_username_scanner.py`** — основной файл программы
- **`requirements.txt`** — зависимости Python
- **`telegram_scanner.session`** — сессия основного аккаунта (создаётся автоматически)
- **`sessions/`** — сессии дополнительных аккаунтов
- **`accounts.json`** — список аккаунтов и API-ключи (создаётся автоматически)
- **`available.txt`** — найденные свободные username (создаётся автоматически)

## ☑️ Распространённые вопросы и проблемы

### Программа пишет FloodWait

Telegram ограничивает частоту проверок. Увеличьте задержку — рекомендуется **1 секунда и больше**.
Программа сама ждёт и увеличивает интервал при FloodWait.

### Где хранятся сессии и результаты?

В папке программы:
- `telegram_scanner.session` — сессия основного аккаунта
- `sessions/` — сессии дополнительных аккаунтов
- `accounts.json` — список аккаунтов и API-ключи
- `available.txt` — найденные свободные username

### Как добавить прокси для аккаунта?

Вкладка **«Аккаунты»** → выберите аккаунт → поле **«Прокси»** → вставьте строку в одном из форматов:

```
socks5://user:pass@host:port
socks4://host:port
http://host:port
host:port
host:port:user:pass
```

### Можно ли запустить на Linux/macOS?

Да, программа написана на Python и кроссплатформенна. Вместо `py` используйте `python3`.
